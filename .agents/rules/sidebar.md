# Sidebar Collapsible Rules

- **Default Closed Menus**: All expandable sidebar menu sections (Projects, Organization, Meetings, etc.) must start CLOSED by default on initial page load.
- **State Persistence**: User collapsible toggles (opening or closing a menu section) are persisted in `localStorage` (`sidebar_collapsible_menu_states`), preserving the exact expanded or collapsed state across page refreshes.
